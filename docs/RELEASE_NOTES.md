# 0.4.0-experience.1

Converges to one verified-experience workflow. Removes selectable assist/strict modes, soft turn reminders, transcript capture, prepare/complete/context/review tools and all Stop handlers from the running product. New knowledge uses only the compact synchronous experience API. Historical search/read remain available; old data/history and bindings are preserved.

The six-tool catalog and one-copy bootstrap/lookup/read payloads remove competing host instructions and duplicate text. Setup replaces owned legacy handlers/arguments without changing other plugins or project rules. Selective wakeup can be disabled independently; disabled/unbound paths do not fall back to a previous workflow.

Maintenance confirmation has a narrow audit-only channel so removing generic writes does not break preview/approval/apply/undo or schedule configuration. Audit excerpts do not participate in business search or experience counts.

No formal Release. Native hook delivery and actual agent consumption remain separate practical acceptance criteria.
