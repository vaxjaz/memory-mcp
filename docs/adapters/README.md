# Host adapters

Select the actual host, not the model. Supported protocol adapters: zcode, codex, qoder, qoder-ide. Use adapters for official protocol references, configuration paths and validation limits.

One workflow installs SessionStart, UserPromptSubmit and, when any opted-in binding uses it, narrowly matched PreToolUse. No Stop handler or raw capture is installed. Windows launchers preserve UTF-8 and quoted paths. Codex uses its native hook trust review. Qoder CLI/IDE share settings: reconcile conflicting managed profiles rather than double-processing input.

Setup/configuration checks and replay tests do not prove the actual client delivered hooks. Preserve unrelated config, handlers and project files.
