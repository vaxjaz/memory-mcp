# Host adapters

Select the actual client and inspect its active configuration. Supported protocol adapters: zcode, codex, qoder, qoder-ide. Use adapters for official protocol references, configuration paths and validation limits.

Setup installs SessionStart, UserPromptSubmit and, when any enabled project binding uses wakeup, narrowly matched PreToolUse and exact-service lookup Pre/PostToolUse observers, plus selected business PostToolUse. ZCode also registers PostToolUseFailure for that lookup. Selected database tool names include mysql_query with or without a native MCP namespace. No Stop handler or raw capture is installed. Windows launchers preserve UTF-8 and quoted paths. Codex uses its native hook trust review. Qoder CLI/IDE share settings: reconcile conflicting managed profiles rather than double-processing input.

Use the [acceptance report](../DELIVERY_ACCEPTANCE.md) to distinguish native ZCode/Codex evidence from Qoder CLI/IDE protocol replays. For an upgrade, rerun setup with the existing service name and library. Fully restart ZCode after regenerating matchers. Reconnect other clients and finish any client trust review. Preserve unrelated config, handlers and project files.
