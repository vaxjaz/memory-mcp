# Host adapters

Select the actual host, not the model. Supported protocol adapters: zcode, codex, qoder, qoder-ide. Use adapters for official protocol references, configuration paths and validation limits.

In 0.6.2, setup installs SessionStart, UserPromptSubmit and, when any enabled project binding uses wakeup, narrowly matched PreToolUse and exact-service lookup Pre/PostToolUse observers, plus selected business PostToolUse. ZCode also registers PostToolUseFailure for that lookup. Selected database tool names include mysql_query with or without a native MCP namespace. No Stop handler or raw capture is installed. Windows launchers preserve UTF-8 and quoted paths. Codex uses its native hook trust review. Qoder CLI/IDE share settings: reconcile conflicting managed profiles rather than double-processing input.

Use the [acceptance report](../DELIVERY_ACCEPTANCE.md) to distinguish native ZCode/Codex evidence from Qoder CLI/IDE protocol replays. If an upgrade changes matchers, rerun setup with the same service name and restart the host. Preserve unrelated config, handlers and project files.
